description: Plan and implement a new plugin feature
---

Help me plan and implement a new feature for the LeanCMS Plugin.

Please follow this workflow:

1. **Feature Discussion**
   - Ask me to describe the new feature
   - Ask about requirements and use cases
   - Clarify any ambiguities

2. **Planning**
   - Create a plan for implementing the feature
   - Identify files that need to be created or modified
   - Consider WordPress best practices and coding standards
   - Identify any potential conflicts or issues

3. **Update Directives**
   - Add the feature to "Planned Features" in docs/start-here.md
   - Update last modified date

4. **Implementation Approval**
   - Present the plan to me
   - Ask if I approve the plan before proceeding
   - Make any adjustments based on feedback

5. **Implementation**
   - Implement the feature following WordPress coding standards
   - Add proper sanitization and escaping
   - Include PHPDoc comments
   - Follow the plugin's existing code style

6. **Testing**
   - Provide testing instructions
   - List what to verify after activation

7. **Documentation**
   - Update README.md if needed
   - Update readme.txt changelog
   - Add inline code comments
   - Update directives to move feature from "Planned" to "Current"

8. **Commit**
   - Create a descriptive commit message
   - Ask if I want to push changes

Remember: Always follow WordPress coding standards and security best practices.
