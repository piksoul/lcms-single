06

Brand Guidelines

Follow these principles to maintain brand consistency and professionalism.

✓ Visual Design Do's

  • Use ample white space
  • Maintain consistent alignment
  • Follow the color palette strictly
  • Use approved typography only
  • Ensure proper contrast ratios

✗ Visual Design Don'ts

  • Overcrowd layouts
  • Use non-brand colors
  • Mix different font families
  • Create busy backgrounds
  • Ignore accessibility standards

✓ Content Do's

  • Write in clear, concise language
  • Use active voice
  • Be professional yet approachable
  • Proofread carefully
  • Focus on benefits for users

✗ Content Don'ts

  • Use jargon or technical terms unnecessarily
  • Write long, complex sentences
  • Be overly casual or formal
  • Make unsubstantiated claims
  • Ignore tone of voice guidelines
